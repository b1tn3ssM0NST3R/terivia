# Terivia
A terminal trivia app written in C.

## Requirements
GCC (the version I used to compile was 16.2.1) or any modern C compiler

# Build
```sh
gcc -Wall -Wextra -o terivia main.c
```

# Run
```sh
./terivia
```

## Features
- Multiple-choice questions
- Score tracking
- Results screen
- Randomized question order
